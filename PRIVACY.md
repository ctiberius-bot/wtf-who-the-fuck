# WTF privacy and data-handling notice

Publisher: JustSignal LLC. Updated November 4, 2026.

WTF is an instruction package, not a hosted data service. JustSignal LLC operates no collection endpoint for this package and receives or retains no research queries, profiles, connection exports or LinkedIn sessions through it.

The user's host agent may process professional names, roles, employers, source URLs, professional photographs, and optional network relationship data using tools the user has authorized. Queries can be sent to the user's selected research providers. Connections exports are read within the authorized workspace; they are not uploaded wholesale to enrichment providers. Live LinkedIn checks require the user's separate choice and authorized session. Credentials are not requested in chat or bundled in this package.

Short briefs appear in the user's chat. Full profiles are saved only when requested to the named destination, with existing access controls. The skill does not send messages or introductions, buy credits, change permissions or schedule monitoring. The user can omit the optional network check.

Host providers, research services, LinkedIn and storage services apply their own policies and retention settings. The publisher cannot delete data held in those services; manage it through the relevant provider. Public professional photos remain subject to their source's rights and usage conditions.

For questions or reports, use the repository's issue tracker. Do not include private profiles, connection exports, credentials or other personal information in a public issue.
